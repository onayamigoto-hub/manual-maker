# 手順書づくり（株式会社アクティブモア）

スタッフが画面に入力するだけで、決まった書式の手順書（Word・PDF）ができるアプリです。

- 公開アドレス：https://onayamigoto-hub.github.io/manual-maker/
- スマホ・パソコンのどちらでも使えます。

## 入力の流れ
1. はじめに（事業所・分類：大分類＞中分類＞小分類）
2. 管理項目（目的・作成者・確認者・作成日・改訂履歴・注意事項・メモ）
3. 全体の流れ（ステップの追加・並べ替え・削除、途中や最後の「確認（分岐）」はいくつでも）
4. 各ステップ（写真・項目・作業手順・注意点・目安時間）
5. 確認・出力（仕上がりイメージ、Word / PDF 出力）

## 動画・写真から下書きをつくる（Claude）
1. 最初の画面の「🤖 動画・写真から下書きをつくる（Claude）」で、動画1本か、順番どおりに撮った写真を選ぶ
2. アプリが「場面一覧」の画像と「指示文」を作る
3. 担当者が自分の Claude アカウントで新しいチャットを開き、指示文と場面一覧を貼って送る
4. Claude の返事を全部コピーしてアプリに貼ると、下書き（写真つき）ができる
- APIは使わない。Windows・Mac・スマホのブラウザで使える。

## 保存について
- 入力内容は、その端末のブラウザの中に自動保存されます（インターネット上には送られません）。
- 別の端末で続きを入力するときは「ファイルに保存」→ 別の端末で「保存したファイルを読み込む」。

## 事業所を追加・変更するとき
`config.js` の `offices` の一覧を直すだけです。

## ファイルの中身
- `index.html` … 画面の入れ物
- `style.css` … 見た目
- `config.js` … 法人名・事業所の一覧
- `app.js` … 入力画面の動き
- `output.js` … 仕上がり表示・Word出力・PDF出力
- `lib/` … Word・PDFを作るための部品（docx 9.5.1 / jsPDF 2.5.2 / html2canvas 1.4.1）
